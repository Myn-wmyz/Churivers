# Churivers · 楚川

惟楚有才，于斯为圣。

于此青丝至皓首，是屈子高义；自其玄云化骄阳，乃伟人壮举。

如此多才的潇湘荆楚，为什么不能有它的衍生模组呢？

楚文化主题内容 Mod：神祇、祭祀、玉石与楚味。

以《九歌》神系（大司命、少司命、东君、湘君、湘夫人、河伯、山鬼、东皇太一、云中君）为主线，包含祭祀、声望、酿造、玉石锤炼、国殇军团等玩法。

## 环境要求

- Minecraft **1.21.1**
- NeoForge **21.1.265+**
- Java **21**
- 纯单机（暂不支持服务器）

## 当前进度：阶段 1 · 基础材料层

- 玉石体系：璞 / 玉 / 瑕 / 玦 / 翠玉 / 良玉 / 珥 / 命玉 / 弦玉 / 玉狱合金锭
- 植物与作物：兰、椒丛、白芷、辛夷、木莲、杜若、麋芜、荻、蕙草、糯米（4 阶段作物）
- 刷子交互：刷璞 5% 得玉（璞刷后消失）、刷火药堆得硫磺，每次刷拭 5 秒
- 酿造原料：曲 / 花曲 / 桂曲
- 粽子：生米粽 / 熟米粽 / 生肉粽 / 熟肉粽（熔炉、烟熏炉、营火均可烧制）
- 可食用粉末：钟乳石粉、硫磺、寒食散
- 配饰与乐器：佩玉、洞箫

完整设计见 [docs/楚川Mod设计文档0.4.md](docs/楚川Mod设计文档0.4.md)。

## 构建

```bash
gradlew build
```

产物位于 `build/libs/`。

## 安装

将 Releases 页面下载的 jar 放入游戏 `mods` 文件夹。
